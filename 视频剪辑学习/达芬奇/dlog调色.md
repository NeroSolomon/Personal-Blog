# DJI D-Log 在达芬奇中的调色节点流程

## 推荐节点结构（6-8个节点）

```
节点1 → 节点2 → 节点3 → 节点4 → 节点5 → 节点6 → 节点7 → 节点8
```

---

## 各节点详细说明

### 节点1：色彩空间转换（CST / 输入转换）

**目的：** 将 D-Log 素材转换到标准色彩空间

- 使用 **Color Space Transform (CST)** 插件
- 输入色彩空间：DJI D-Gamut / D-Log
- 输出色彩空间：Rec.709 / Gamma 2.4（或你选择的工作空间）
- 或者直接套用 DJI 官方提供的 LUT 作为基础转换

> **替代方案：** 如果使用达芬奇色彩管理（DaVinci YRGB Color Managed），可以在项目设置中完成此步骤，该节点则可省略或用作微调。

---

### 节点2：曝光/亮度校正（一级校正 - Primary Correction）

**目的：** 修正曝光，建立正确的亮度基础

- 调整 **Lift / Gamma / Gain**
- 修正整体曝光（Offset）
- 看波形图（Waveform），确保：
  - 高光不溢出
  - 暗部有合适的黑点
  - 整体曝光正确

---

### 节点3：白平衡/色温校正

**目的：** 修正色温和色调偏移

- 调整 **色温（Temperature）** 和 **色调（Tint）**
- 使用示波器中的矢量示波器辅助判断
- 确保肤色、中性灰等关键颜色准确

---

### 节点4：对比度/色调曲线（二级校正基础）

**目的：** 建立画面的对比度和层次感

- 使用 **自定义曲线（Custom Curves）**
- 拉 S 曲线增加对比
- 分别调整 RGB 各通道的层次
- 也可以使用 **Log 色轮** 精细调整暗部/中间调/高光的色彩倾向

---

### 节点5：二级校色 - 局部调整（肤色/天空等）

**目的：** 对特定颜色或区域做针对性调整

- 使用 **限定器（Qualifier）** 选取特定颜色范围
  - 肤色矫正
  - 天空增蓝/压暗
  - 植被调绿
- 使用 **Power Window** 做局部区域调整
- 可以根据需要拆分为多个并行节点

---

### 节点6：二级校色 - Power Window / 遮罩

**目的：** 局部亮度/颜色修正

- 压暗边角（暗角效果）
- 提亮主体
- 修正画面中局部过曝/过暗区域
- 渐变滤镜效果（如压暗天空）

---

### 节点7：整体风格化 / Look

**目的：** 赋予画面创意色调和整体风格

- 应用整体的色彩风格
- 高光偏暖 / 阴影偏冷（或其他风格倾向）
- 调整整体饱和度（Saturation）
- 色相偏移等创意调整
- 也可在此叠加创意 LUT

---

### 节点8：最终修饰（输出限制）

**目的：** 最后的安全检查和微调

- 确保信号在合法范围内（Broadcast Safe / 限幅器）
- 最终的锐化或柔化
- 最终的整体饱和度微调
- 添加胶片颗粒（Film Grain）等质感效果

---

## 节点连接方式总结

```
[串行为主]

1.CST → 2.曝光 → 3.白平衡 → 4.对比/曲线 → 5.局部颜色 → 6.局部亮度 → 7.风格 → 8.输出
                                                    ↑
                                              (可并行多个)
```

---

## 实用建议

| 建议 | 说明 |
|------|------|
| **给节点命名** | 右键节点 → 添加标签，方便管理 |
| **先校正后创意** | 节点1-4是"还原真实"，节点5-8是"创意表达" |
| **不要过度** | D-Log 的动态范围优势在于暗部和高光细节，不要一味拉对比把它们丢掉 |
| **善用示波器** | 每个节点调整时都参考波形图、矢量图、直方图 |
| **节点数量灵活** | 简单镜头可能3-4个就够，复杂镜头可能10个以上 |

---

## 关于 DaVinci 色彩管理的选择

你有两种工作流可选：

1. **手动 CST 流程**（上述方案）：灵活度高，适合学习和精细控制
2. **DaVinci Color Management (DCM)**：在项目设置中设定输入/输出色彩空间，达芬奇自动做转换，节点1可以省略，直接从曝光校正开始

两种方式都是行业标准，选择你更习惯的即可。
