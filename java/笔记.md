## mac环境配置
第一步：安装 JDK 21
brew install openjdk@21
第二步：创建系统符号链接（让 /usr/libexec/java_home 能识别到它）
sudo ln -sfn /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
第三步：配置环境变量，追加到 ~/.zshrc
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 21)' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
第四步：验证
java -version
javac -version
echo $JAVA_HOME
#### 如需多版本切换，可加别名
alias java17='export JAVA_HOME=$(/usr/libexec/java_home -v 17) && export PATH="$JAVA_HOME/bin:$PATH"'
alias java21='export JAVA_HOME=$(/usr/libexec/java_home -v 21) && export PATH="$JAVA_HOME/bin:$PATH"'

## vscode插件
VS Code 做 Java 开发，核心插件只需一个扩展包搞定：
必装
- Extension Pack for Java（微软官方出品，ID: vscjava.vscode-java-pack）
这个包会自动安装以下 6 个插件：
- Language Support for Java — 语法高亮、自动补全、重构
- Debugger for Java — 断点调试
- Test Runner for Java — JUnit/TestNG 测试运行
- Maven for Java — Maven 项目管理
- Project Manager for Java — 项目视图
- IntelliCode — AI 代码补全
按需选装
| 插件 | 用途 |
|---|---|
| Gradle for Java (vscjava.vscode-gradle) | 如果用 Gradle 构建 |
| Spring Boot Extension Pack (vmware.vscode-boot-dev-pack) | Spring Boot 项目开发 |
| Lombok Annotations Support (GabrielBB.vscode-lombok) | 项目用了 Lombok |
| XML (redhat.vscode-xml) | 编辑 pom.xml 有提示 |
| Docker (ms-azuretools.vscode-docker) | 容器化部署 |

## Java修饰符
像其他语言一样，Java可以使用修饰符来修饰类中方法和属性。主要有两类修饰符：

- 访问控制修饰符 : default, public , protected, private
- 非访问控制修饰符 : final, abstract, static, synchronized

## Java 变量
Java 中主要有如下几种类型的变量
- 局部变量
- 类变量（静态变量）
- 成员变量（非静态变量）
