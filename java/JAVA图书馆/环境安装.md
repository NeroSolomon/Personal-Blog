## JDK
方式一：Homebrew（macOS 最简单）
brew install openjdk@21
安装后设置环境变量（终端会提示你执行类似命令）：
echo 'export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
echo 'export JAVA_HOME=$(/usr/libexec/java_home)' >> ~/.zshrc && source ~/.zshrc

方式二：官网下载安装包
1. 打开 Adoptium (https://adoptium.net/download/)（推荐，开源免费）
2. 选 JDK 21、macOS、架构选 aarch64（M 系列芯片）或 x64（Intel 芯片）
3. 下载 .pkg 安装包，双击安装即可

## maven
brew install maven

### 用Extension Pack for Java的话不需要手动安装
在 VS Code 中不用手动装 Maven 也能创建项目，用内置向导：
1. 打开 Command Palette：Ctrl+Shift+P
2. 输入并选择 Java: Create Java Project...
3. 选 Maven 构建工具
4. 选 archetype（模板），列表里可能有直接可用的选项，如果没有就用默认的 maven-archetype-quickstart
5. 依次填入：
   - Group Id：com.yourcompany.library
   - Artifact Id：book-manager
6. 选择项目存放文件夹，点确认
VS Code 会自动生成完整的项目结构（pom.xml + src/main/java + src/test/java），效果和你手动跑 mvn archetype:generate 一样。
> 生成的 pom.xml 后续改为 Spring Boot 项目的格式就行（这个是你下一步要做的事）。

#### Maven	含义	Node.js 类比
Group Id	组织/公司标识，通常是域名倒着写	package.json 里的 name 的 scope 部分，如 @mycompany
Artifact Id	这个项目本身的名称	package.json 里的 name 的主体部分，如 my-app

## mysql
本地启动 MySQL
安装并启动：
brew install mysql
brew services start mysql
创建数据库：
mysql -u root -e "CREATE DATABASE book_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
（默认 root 无密码，直接回车）
然后改 pom.xml 和 application.properties：
1. pom.xml 里把 H2 依赖换成：
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
2. src/main/resources/application.properties（还没建的话先建这个文件）：
# 数据库连接
spring.datasource.url=jdbc:mysql://localhost:3306/book_manager?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=
# JPA 配置
spring.jpa.hibernate.ddl-auto=update（ddl-auto=update 意思是启动时自动建表（类比 Sequelize 的 sync），你写好 Entity 类，表自动就出来了。）
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect
