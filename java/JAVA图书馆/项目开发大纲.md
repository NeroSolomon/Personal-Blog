用 Java 开发部门图书管理系统 — 逐步指引
以下是一步步的做法，我会尽量对照 Node.js 中你熟悉的概念来类比。
---
第一步：搭建 Java 开发环境
1. 安装 JDK（Java Development Kit）
   - 下载 JDK 17 或 21（LTS 长期支持版本），推荐 Adoptium/Eclipse Temurin (https://adoptium.net)
   - 类比 Node.js 的 node 运行时，JDK = node + npm 合体
2. 安装 IDE
   - 推荐 IntelliJ IDEA Community Edition（免费），这是 Java 界的 VS Code
   - 或者用 VS Code 装 Java 扩展包也行
3. 安装 Maven（或者用 IDE 自带的）
   - Maven ≈ Node.js 的 npm，负责依赖管理和构建
   - 配置文件叫 pom.xml，类比 package.json
4. 验证环境
      java -version
   mvn -version
   
---
第二步：创建项目骨架
用 Maven 命令创建标准项目结构（类比 npm init）：
mvn archetype:generate \
  -DgroupId=com.yourcompany.library \
  -DartifactId=book-manager \
  -DarchetypeArtifactId=maven-archetype-quickstart \
  -DinteractiveMode=false
生成后的目录结构类比：
Java 项目
src/main/java/
src/main/resources/
src/test/java/
pom.xml

### 第四步：设计数据模型
一个最基本的图书管理系统需要这几张表：
1. **book（图书表）**：书名、作者、ISBN、分类、库存数量、位置
2. **borrow_record（借阅记录表）**：借书人、图书ID、借出日期、归还日期、状态
3. **user（用户表，可选）**：部门成员信息
建议先用 Excel 或纸笔把字段列清楚，再动手建表。

第五步：选择技术栈
考虑到你是 Node.js 背景、目标是部门内部小系统，推荐以下组合（最主流、文档最多）：
层次

> 它是 Java Web 开发的事实标准，自带 Tomcat（类比 Express 自带 http server），配置少，社区大，教程多，适合新手。

### 第六步：动手开发 — 按顺序来
#### 6.1 在 `pom.xml` 中添加依赖
你需要加这几个起步依赖（Spring Boot 称之为 starter）：
- `spring-boot-starter-web` — Web 能力
- `spring-boot-starter-data-jpa` — 数据库 ORM
- `spring-boot-starter-thymeleaf` — 页面模板
- `h2` 或 `mysql-connector-java` — 数据库驱动
#### 6.2 配置数据库连接
在 `src/main/resources/application.properties` 中写连接信息，类比 Node.js 的 `.env` 文件。
#### 6.3 创建实体类（Entity）
这是你第一个要写的 Java 类。一个实体类对应数据库的一张表：
- `Book.java` — 用注解 `@Entity`、`@Table` 标记
- 字段加 `@Id`、`@GeneratedValue`、`@Column` 等注解
- 类比：Node.js 里 Sequelize 的 `model.define()`
#### 6.4 创建 Repository 接口
这是你接触的第一个"Java 特色"——只需声明接口，不用写实现：
- 定义 `BookRepository` 接口，继承 `JpaRepository<Book, Long>`
- Spring Data JPA 会在运行时**自动生成实现类**
- 类比：Sequelize 的 `User.findAll()` 这种内置方法，但更强大
#### 6.5 创建 Service 层
- `BookService.java` — 放业务逻辑（借书、还书、查询等）
- 用 `@Service` 注解标记
- 类比：Node.js 里的 service 层，把逻辑从路由中抽出来
#### 6.6 创建 Controller 层
- `BookController.java` — 处理 HTTP 请求
- 用 `@Controller` 注解标记
- `@GetMapping`、`@PostMapping` 对应 `app.get('/path', handler)` 和 `app.post(...)`
#### 6.7 写 Thymeleaf 模板页面
- 放在 `src/main/resources/templates/` 下
- 文件后缀 `.html`
- 语法类似 EJS：`th:text="${book.title}"` 渲染变量
- `th:each="book : ${books}"` 循环渲染列表
#### 6.8 创建启动类
- 一个带 `@SpringBootApplication` 和 `main` 方法的类
- 运行它就能启动整个应用（内嵌 Tomcat）
- 类比：`node app.js`
---
第七步：页面的功能清单
建议按这个顺序实现，从简到繁：
1. 图书列表页 — 展示所有图书，分页
2. 添加图书页 — 表单录入新书
3. 借阅功能 — 点击"借阅"，生成借阅记录，库存减 1
4. 归还功能 — 点击"归还"，更新借阅记录状态，库存加 1
5. 借阅记录查询 — 查看谁借了什么书、是否逾期
6. 搜索功能 — 按书名、作者搜索
---
第八步：运行和测试
# 在项目根目录
mvn spring-boot:run
访问 http://localhost:8080 就能看到页面。
- 开发阶段用 H2 内嵌数据库（重启数据就没了，适合调试）
- 需要持久化时切换到 MySQL
---
学习路径建议
1. 先看 Spring Boot 官方 Quick Start（15 分钟能跑起来 Hello World）
2. 重点学注解：@Entity、@Repository、@Service、@Controller、@Autowired 这 5 个注解理解了，就能写 CRUD
3. 遇到报错不要慌：Java 的报错信息通常很长，看最底部的 Caused by: 那句，通常就是根因
4. 用 IDE 的自动补全：IntelliJ IDEA 对 Spring Boot 支持极好，输前几个字母就能补全
